# Database SQL Introduction 20

MySQL을 사용하여 관계형 데이터베이스와 SQL의 기본 문법을 학습하고 정리한 저장소입니다.

데이터 조회와 변경부터 조건 검색, 정렬, 집계 및 그룹화까지 SQL의 기본적인 데이터 처리 흐름을 연습했습니다.

## 학습 내용

- 데이터베이스 및 테이블 생성
- `SELECT`를 활용한 데이터 조회
- `WHERE`와 조건식을 활용한 데이터 필터링
- `INSERT`, `UPDATE`, `DELETE`를 활용한 데이터 변경
- `NULL` 데이터 처리
- 집계 함수 활용
- `GROUP BY`, `HAVING`을 활용한 그룹별 데이터 분석
- [개념 정리 문서 보기](./docs)

## 학습 포인트

- 필요한 데이터를 조건에 따라 조회하고 정렬하는 방법을 학습했습니다.
- 데이터를 추가, 수정, 삭제하는 기본적인 SQL 사용법을 익혔습니다.
- `NULL`이 일반적인 값과 다르게 처리되는 특징을 학습했습니다.
- 집계 함수와 `GROUP BY`, `HAVING`을 활용하여 여러 데이터를 그룹 단위로 분석하는 방법을 연습했습니다.
